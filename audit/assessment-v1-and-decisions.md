- `queries` хранит question/answer без TTL; wipe удаляет documents/chunks и очищает suggestions, но не queries. Redis idempotency TTL по умолчанию сутки; последнее settled Ask state сохраняется в sessionStorage. Сроки/обращения/резервные копии ещё не согласованы.
- `app/generation/suggestions.py` отправляет restricted sample в LLM; `drop_leaky` фильтрует цифры/валюту, не имена или иные текстовые секреты. Нужен synthetic prompt-injection/non-numeric disclosure test, сейчас UNVERIFIED.
- Saved [eval/results_large_openai.md](../eval/results_large_openai.md) и [eval/results_access.md](../eval/results_access.md) описывают top-8/vector-30; текущий Settings — top-20/vector-100. Старые цифры не приняты за оценку текущего release/config. Live eval требует выбранных параметров, критериев и бюджета.
- В installed metadata PyMuPDF указан `Dual Licensed - GNU AFFERO GPL 3.0 or Artifex Commercial License`; происхождение публичных корпусов, выбранное разрешение и обязательные notices требуют отдельной записи. В этом аудите не делался правовой вывод о соблюдении/нарушении.
- UI state handling, auth scopes и reuse patterns изучены; blanket WCAG conformance, полная лицензия/законность, отсутствие всех XSS и полномасштабный ASVS не подтверждаются таким методом.

**E-10 — проверка отчёта и сохранности дерева.** Сверить ID заголовков каталога со строками реестра; допустимые значения статусов; N/A только с NO; наличие обоснований/ссылок; неизменность исходных SHA и HEAD; отсутствие staged changes. ## 8. Замечания к фреймворку

- Для RAG состояние «ещё не классифицировано» должно входить в проверку оригиналов, не только ready chunks: APP-002 поймал случай, который существующие role tests не проверяли.
- Content-addressed storage требует проверки lifecycle общих файлов при admin/cron операциях, а не только HTTP delete: APP-004. DATA-04 и FLOW-04 охватывают риск, но конкретный инвариант полезно фиксировать явно.
- PASS штатного тестового набора не заменяет fault injection реального worker. Eager Celery скрывал дефект retry и разрыв commit→enqueue.
- При аудите demo/trusted-integrator API необходимо сначала прочитать модель role claims: произвольный выбор роли был бы ложноположительной находкой. Реальные нарушения read_only и pending originals при этом нельзя исключать как «просто демо».
- Применимость LEG и внешних проверок не определяется тем, что в репозитории нет соответствующих страниц/настроек. В текущем отчёте такие сведения оставлены UNKNOWN/UNVERIFIED с конкретным следующим действием.

Общий стандарт и шаблон в ходе испытания не редактировались.
