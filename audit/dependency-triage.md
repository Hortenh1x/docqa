# W-07 — применимость advisories и выбранное обновление

Проверка 2026-09-10 для локального рабочего дерева. Выбран **Next 15.5.25 + sharp 0.35.4**; React/react-dom остаются 19.2.7. Next 15.5.24 — минимальная исправленная версия; [15.5.25](https://github.com/vercel/next.js/releases/tag/v15.5.25) возвращает AVIF при наличии исправленного sharp. Scoped override нужен: старый sharp 0.34.5 всё ещё удовлетворяет диапазону зависимости Next.
