## 2. Контекст для работы и выпуска

Сервис предназначен для ознакомления всех пользователей с RAG-функционалом; владелец отвечает за него, злоупотребления/противоправное/корыстное использование не разрешены. Гость видит только явно опубликованный read-only corpus. Подтверждённый аккаунт загружает документы в отдельный personal tenant. Публичный role selector демонстрирует content labels и не управляет правом на чужой personal tenant.

Python3.12/FastAPI/SQLAlchemy/Alembic/Celery, PostgreSQL18/pgvector, Redis7; Next15/React/Node22. Локальные tests используют отдельные testcontainers и synthetic данные. Для paid eval read-only скопированы только три именованные synthetic коллекции (320 документов); исходная БД не изменялась, реальные пользовательские документы не отправлялись. Ключи читаются из приватного env и не попадают в evidence.

Файлы хранятся локально с fsync либо в versioned S3 с проверкой checksum и локальным cache. Chunks/embeddings, owners, sessions, queries и reservations — PostgreSQL. Embedding provider получает тексты/вопросы; LLM — вопрос и выбранные passages. Идентификатор гостя — HMAC IP (IPv6 /64), с общим лимитом для NAT. Cookie Secure/HttpOnly/SameSite=Lax; private UI данные только в памяти. Google получает запрос входа по выбору пользователя, DocQA — проверенный email и устойчивый Google subject; доступ к Gmail/Drive не запрашивается. Подробности: [accounts](docs/accounts.md), [billing](docs/billing.md), [данные](audit/data-and-licenses.md).

Downtime допустим, acknowledged data loss не принят. Production release `prod-20260912-google`: migration0012, accounts/budget/SMTP/Google включены, originals в private versioned Oracle Object Storage, primaryAD1→standbyAD2 по TLS/private network. Release gate проверил все9778 оригиналов; реальный failure drill подтвердил сохранение acknowledged row и блокировку нового commit без standby. Процедура manual failover описана в [durability](deploy/durability.md); реального production promotion не было. Старые HTTP520/403 наблюдения v1 не описывают текущее состояние.
